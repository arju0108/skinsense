# SkinSense AI

An AI-powered skincare product analyzer that provides personalized ingredient analysis and recommendations.

## 🎯 Features (In Progress)

- [ ] Fetch product ingredients from URL
- [ ] AI-powered ingredient analysis using Claude API
- [ ] Personalized scoring based on skin type
- [ ] Alternative product recommendations
- [ ] Review sentiment analysis
- [ ] Streamlit web interface

## 🛠️ Tech Stack

- **Python** — core language
- **Claude API** — AI analysis
- **Streamlit** — web interface
- **SQLite** — product storage
- **Pandas** — data handling
